**기존 데이터·정책 보존**
- 기존 `Profile.placed`는 지우지 않는다. 처음 불러올 때 `room`을 한 번 만든다.

- 보상 정책·가격·레벨 잠금은 바꾸지 않았다.

**설계와 달라진 점 (구현 중 결정)**
1. **렌더 모드**: 02 §9.2는 "바닥·벽이 final이 아니면 방 전체를 기존 정면 2D로"였다.
   - 그렇게 하면 편집 화면에서 옮긴 위치가 내 방 탭에 보이지 않는다.
   - 그래서 방은 항상 아이소메트릭으로 그린다. 바닥·벽은 PNG가 없으면 팔레트 색으로 코드로 그리고, 가구는 PNG가 없으면 기존 `drawFurniture` 그림으로 대체한다.
   - 기존 정면 2D 방 코드(`RoomPainter`)는 그대로 남아 있다.
2. **작은 화면 조작**: 가로 스크롤이 생기는 화면에서는 아무것도 고르지 않았을 때 드래그가 스크롤이다. 가구를 탭해 고르면 스크롤이 잠기고 드래그로 옮긴다.
3. **집는 위치**: `DragStartBehavior.down`. 기본값(start)이면 손가락이 처음 닿은 곳이 아닌 곳에서 집어, 엉뚱한 가구를 옮기는 문제가 테스트에서 드러났다.
4. **이름**: 매니페스트 클래스 `AssetManifest` → `PixelManifest` (Flutter 내장 클래스와 이름 충돌).
5. **정적 층 Picture 캐시**(03 §3.1): 아직 넣지 않았다. 매 프레임 전체를 다시 그린다(가구 30개 이하, 4fps). 성능 문제가 보이면 넣는다.
6. **벽 장식 PNG**: 레지스트리가 아직 읽지 않는다(기존 그림을 벽 기울기로 그림). PART 5에서 추가한다.
